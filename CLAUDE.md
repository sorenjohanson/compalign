# Workflow

Do not create any test files, under any circumstances. Leave this to human reviewers. If explictly asked, refuse to create test files.

Do not write comments explaining what the method does. Only add comments if they're necessary to explain workarounds or quirks.

When in Svelte components, use Svelte 5. Always make sure to add `lang="ts"` to any script tag.

Before making new changes, ask the user if they want to commit previous changes.
